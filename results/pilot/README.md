# Hyperparameter pilot (archived)

Two-seed pilot runs made before the main experiment, kept so that the choice of
DQN settings can be checked. They were produced with the code as of commit
`83c51e8` (stage 1 just before it), are not regenerated by any `make` target, and
their checkpoints are not included.

- `stage1/`: monitorability-aware agents, both encoders, learning rate {1e-3, 3e-4} x
  hard target update every {200, 1000} steps.
- `stage2/`: Polyak-averaged targets (tau = 0.005) at both learning rates, for the
  monitorability-aware agents and for outcome-only agents with the invariant encoder.

Each run was evaluated on training lengths (3-6) and on lengths 7-9. The setting
used everywhere else (learning rate 1e-3, hard update every 200 steps) was kept
because it had the highest training-length success among the stage-1 settings for
the invariant agents and was close to the best for the absolute ones. Polyak
averaging did as well for the invariant agents and better for the absolute ones; it
is one of the alternatives re-run with five seeds in `results/sensitivity/`, where
the encoder gap and the outcome-only vs. monitorability-aware comparison hold. The
original setting was kept for continuity with the project's first version, not
because it was clearly best. Because lengths 7-9 were also measured here, they
were not completely untouched by this choice; lengths 10-14 were never evaluated
in the pilot.
